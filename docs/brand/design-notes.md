# Dono — design notes

## Brief

Dono connects donors with nonprofit associations that actually need their items. The identity should feel precise, calm, friendly and trustworthy. It should be recognizable at 16 px, fit the existing grass/sand palette, and read with a lowercase dono wordmark. Existing references: ../../DESIGN.md and ../design/01-landing.html. Logo work only; no landing-page changes.

The name is short enough for a custom geometric wordmark. Assume the main uses are a website header, donor/mobile interface, association console and browser tab. The wordmark is drawn specifically for Dono; DM Sans remains the interface typeface.

## Research and boundaries

The installed logo-design library has no nonprofit category. The productivity/collaboration collection was used as an adjacent reference: its common devices include containment, modular repetition and segmented colour. Four short SVG constructions were studied to understand primitive count, counters and optical spacing. These were references for craft, not source artwork.

Excluded: hearts, hands, gift/donation boxes, leaves, recycling arrows, stock chain links, shields, illustrative objects, gradients and shadows. A leaf would push the identity toward ecology alone; a shield would imply verification; a checkmark could blur the product's staff-only decision rule. None is part of the selected mark.

Word map: give → pass → receive; need → space → fit; association → counterpart → meet; dono → d / o / paired circular bowls. The useful intersection is **a place that fits**, rather than a literal donation object.

## Concept longlist

Scores are comparative designer judgments on a 1–5 scale, not user-research measurements.

| Direction | Mark type | One-line construction | Clarity / distinction / simplicity / relevance / small size |
|---|---|---|---|
| **Right fit** | Letterform | One segment fits within two open seams of a geometric D. | 5 / 4 / 5 / 5 / 4 |
| **Reciprocal** | Abstract | Two rotated receiving corners balance across a shared centre. | 4 / 4 / 5 / 4 / 5 |
| **Converge** | Abstract | Two opposing rounded triangles define a diagonal shared opening. | 4 / 3 / 5 / 4 / 5 |
| Shared counter | Wordmark | The two o counters are offset toward one another. | 3 / 3 / 4 / 3 / 2 |
| Matched pair | Letterform | Two mirrored d forms create one compact emblem. | 3 / 3 / 3 / 4 / 3 |
| Common opening | Abstract | Two unequal arcs meet around one aperture. | 3 / 3 / 4 / 4 / 4 |
| Aligned endpoints | Abstract | Two dots meet one short connecting bar. | 4 / 2 / 5 / 4 / 5 |
| Open interval | Wordmark | An intentionally open o repeats in the name. | 3 / 3 / 4 / 3 / 3 |
| Shared module | Abstract | Two offset rounded tiles share a small square interval. | 3 / 3 / 4 / 4 / 4 |
| Receiving notch | Letterform | A square-ended d receives a small circular piece. | 3 / 3 / 4 / 4 / 3 |

Only the selected three were built. The three use different overall silhouettes: a rounded D, paired reciprocal corners, and a diagonal divided square.

## Refinement

1. Built filled black geometry and a common original lowercase wordmark. Compared large silhouettes and 64/32/16 px samples in the logo skill's concept sheet.
2. Right fit was strongest because it identifies the brand name while retaining a small visual idea. Reciprocal is more abstract and can be read as S; Converge is very economical but less specific.
3. Softened the D's two outer stem corners from square to 16-unit radii. Kept the matching piece at 48 × 32 with 16-unit gaps so the relationship remains visible without delicate details.
4. Adjusted the mark 8 units right for optical mass, retained a 2-unit wordmark overshoot and tightened the lockup spacing. Re-audited and re-rendered.
5. Inspected positive/reversed, native-size and enlarged-pixel samples. Verified the presentation in a real 390 px viewport using browser emulation, rather than relying on Chrome's minimum desktop window width.

The initial recommendation was Right fit. The user subsequently selected **Reciprocal**, the middle concept. All main exports, the favicon and the comparison page now use that direction. Its two identical 48-unit forms are balanced through 180-degree rotation; the original lowercase wordmark is retained. Right fit and its iterations remain exploration history.
